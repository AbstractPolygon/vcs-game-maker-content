# Dictionaries

Dictionaries for the AtariVox text to speech of VCS Game Maker, one `word = \SpeakJet \words` per line (the PhraseALator `.Dic` format).

- `Default.Dic` - the built-in dictionary of the app: the PhraseALator dictionary (1,423 words). Portions of it are provided by and copyrighted by Magnevation LLC.
- `CMU.Dic` - about 122,000 words, converted from the CMU Pronouncing Dictionary (`cmudict.dict`, version 0.7b) with the sound table of the app, using the first pronunciation of each word. The app offers it as an optional download. Copyright (C) 1993-2015 Carnegie Mellon University, under the licence in `LICENSE.cmudict`.
