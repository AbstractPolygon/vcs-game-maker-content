# Sound banks

Sound banks (`.vcsbnk`) go in `banks/` and single sounds and instruments (`.vcssnd`)
in `instruments/`, as saved by the export icons on the Sound tab (`.json` files work
too). The Sound Banks screen on the Project tab lists everything below this folder
(folders two deep are read) and imports it into the open project; the filter there
sorts by what a file holds: sound banks, sounds, instruments or percussion.
